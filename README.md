# Merkasoft Renamer
Bulk file renamer with specific focus on images with EXIF data

Core logic based on [photo-rename](https://github.com/matthewmerkas/photo-rename).
Vibe coded with Gemini 3.6 Flash Extended

```shell
python -m venv venv

python -m pip install -r requirements
python main.py
```
